OFFICE ESC
Point & Click Escape Room
Project Description

A classic point-and-click escape room inspired by the Liminal Horror aesthetic. You've been locked inside an abandoned office building. Solve a puzzle in each room to find your brother and escape.

GitHub Collaboration

This project was built collaboratively using GitHub, with each developer responsible for different areas within the project. Shared resources like images and audio were organized into dedicated folders. Regular commits and branches ensured that all updates and contributions were consistently merged into the repository. Using GitHub helped streamline collaboration, manage files efficiently, and track progress throughout development.
